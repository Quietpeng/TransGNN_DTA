TransGNN_DTA：Transformer + GNN 的药物靶点亲和力回归实现

English

最后更新：2026-11-01 · Apache-2.0 · Python 3.12 / PyTorch 2.3.0 / CUDA 12.4

一句话：TransGNN_DTA 是一个科研代码仓库，用 TransGNN 做药物靶点亲和力（DTA）回归——药物 SMILES 与蛋白序列走分块 Transformer 编码器，再经 GNN 消息传递，最后由回归解码器输出一个亲和力数值；仓库里带齐了预处理、训练和加载权重的脚本，可以在自己的 GPU 上跑 DAVIS 与 KIBA 实验。

方法：四个阶段各自在做什么

模型分四段。增强嵌入层把药物 SMILES 与蛋白序列变成词嵌入加位置嵌入，再做归一化与 dropout；编码器模块堆叠带前馈的注意力层，沿序列抓上下文；GNN 层做消息传递，让分块表示之间的结构信息互相流动；解码器模块把特征映射成一维输出，也就是预测的结合亲和力。

训练侧用 MSE 作回归损失、AdamW 更新参数、ReduceLROnPlateau 按验证集损失调学习率，并用 GradScaler 与 autocast 做混合精度以省显存、加快步进。早停监控验证损失，patience 可调（README 示例是 EarlyStopping(patience=20)），触发时可发邮件通知。测试路径返回的指标是 mse、r2、CI 与回归损失，实现在 util_function.py。

序列是按块切分而不是截断：配置里 drug_max_seq 为 50、target_max_seq 为 545，长蛋白会被切成窗口分别编码再由 GNN 聚合——这正是论文标题里 "chunked" 的含义，也是它能处理远长于小分子的蛋白的原因。

复现一次训练：完整命令序列

  1. 建环境：python -m venv transgnn_env && source transgnn_env/bin/activate。
  2. 克隆并装依赖：git clone https://github.com/Quietpeng/TransGNN_DTA.git && cd TransGNN_DTA && pip install -r requirements.txt。锁定版本是 scikit-learn 1.5.2、scipy 1.14.1、subword-nmt 0.3.8、PyYAML 6.0.1、numpy 2.1.3、pandas 2.2.3、tensorboard 2.18.0（requirements.txt）。
  3. 选配置：改 config.json 或用 --model_config 指定；默认就是 50/545 序列上限、256 维嵌入、64 头、2 层。
  4. 训练：python train_reg.py --model_config config.json --lr 0.001 --b 32 --epochs 100 --dataset raw_davis。--dataset 支持 benchmark_davis、benchmark_kiba、raw_davis、raw_kiba。
  5. 看曲线：tensorboard --logdir=./log，再转发 6006 端口（ssh -L 6006:localhost:6006 user@server_ip）打开 http://localhost:6006。
  6. 评估或预测：用 torch.load(..., weights_only=True) 载入 models/ 下的权重，按 checkpoint 形状重建解码器输入维度，再把 SMILES 与蛋白序列送进编码器。README 的推理片段就是这一步。

端到端笔记本是 Example.ipynb（中文）与 Example_en.ipynb，从装环境、训练到预测都走一遍。

数据可用性

和多数 DTA 仓库不同，数据就在树里：dataset/regression/DAVIS、dataset/regression/KIBA，另有 BindingDB、ChEMBL 目录与 dataset/regression/benchmark 下的 benchmark 划分。四个预训练权重（各约 101 MB）也在 models/，可以先评估再决定要不要训练。词表在 vocabulary/，preprocess.py 的编码器依赖它，不确定要重训时不要重建词表。

常见问题（FAQ）

药物和靶点的结合亲和力怎么预测？

在这个仓库里的最短路径分三步：先训练、再载权重、最后推理。用 train_reg.py 在 DAVIS 或 KIBA 上训练，再从 models/ 载入权重，把一条 SMILES 和一段蛋白序列送进 preprocess.py 的编码器。README 给了完整的推理片段，输出是四位小数的亲和力回归值，不是分类标签。

DAVIS 数据集上跑 DTA 模型，有没有现成代码？

有，就是这个仓库本身，数据已随仓库提供：dataset/regression/DAVIS，训练命令是 python train_reg.py --model_config config.json --lr 0.001 --b 32 --epochs 100 --dataset raw_davis。想做 benchmark 划分对比就换成 --dataset benchmark_davis，两者用的是同一套脚本。

transformer 加 GNN 做药物靶点回归怎么实现？

按这里的实现顺序是：增强嵌入层做词嵌入加位置嵌入，编码器堆叠注意力层抓序列上下文，GNN 层在分块表示之间做消息传递，解码器把特征回归成一维亲和力。配置里 2 层编码器、64 个注意力头、256 维嵌入，代码在 double_towers.py。

想复现药物靶点亲和力论文的实验，从哪一步开始？

从环境开始：Python 3.12 + PyTorch 2.3.0 + CUDA 12.4 与 README 一致，pip install -r requirements.txt 装锁定的依赖，然后按 config.json 的训练命令跑。本页不提供任何复现分数字，因为它不在仓库 README 里；你跑出来的数才是可引用的数。

训练这个模型需要多少显存？

README 记录的参考实验是单张 32 GB vGPU。训练循环已内置混合精度（GradScaler 与 autocast），小卡可以通过调小 --b（默认 32）来跑，代价是耗时变长；序列上限 50 与 545 也直接决定显存占用。

仓库里有没有现成的预训练权重？

有，一共 4 个，都放在仓库的 models/ 目录：DAVIS 与 KIBA 各一份 best-CI 和 best-MSE，每个约 101 MB。载入时需要按 checkpoint 里的形状重建解码器输入维度（README 片段演示了这一步），因为解码器是在加载时重建的。

DAVIS 与 KIBA 的数据从哪来，仓库里带吗？

带，数据和代码在同一个仓库里。dataset/regression 下有 DAVIS、KIBA，以及 BindingDB、ChEMBL 目录和 benchmark 划分；代码按 README 给的路径取数：benchmark 集在 dataset/regression/benchmark，raw 集在 dataset/regression。
